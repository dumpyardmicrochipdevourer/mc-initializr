Установка на VPS

  1. Скачайте ZIP

    Выберите настройки и скачайте архив. Файлы можно просмотреть до скачивания.

  2. Распакуйте на VPS

    Ubuntu 24.04 или Debian 12/13. Нужны root-доступ, интернет и память Java плюс 1–2 ГБ для системы.

  3. Запустите скрипт

    В папке архива выполните:

    sudo bash setup.sh

    Ansible установит Docker и запустит контейнер. Откройте игровой TCP-порт в панели VPS. Команды управления и восстановления — в README.md.

Ключи S3 вводятся на VPS. Сайт их не запрашивает.

ZIP сформирован

Перенесите ZIP на VPS, распакуйте и выполните в папке архива:

sudo bash setup.sh

После запуска подключитесь к IP VPS и выбранному порту. Инструкции — в README.md.
